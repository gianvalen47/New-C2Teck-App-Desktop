## 🎓 GLOSARIO RÁPIDO

- **WCF**: Windows Communication Foundation (servicios web .NET)
- **SUNAT**: Superintendencia Nacional de Aduanas y de Administración Tributaria (Perú)
- **RDLC**: Report Definition Language Client (reportes SQL Server)
- **Service Reference**: Proxy autogenerado de servicios SOAP/WCF
- **MDI**: Multiple Document Interface (interfaz VB.NET)
- **LOC**: Lines of Code
- **ORM**: Object-Relational Mapping (Prisma)
- **API**: Application Programming Interface
- **SPA**: Single Page Application (React)
- **SEO**: Search Engine Optimization
